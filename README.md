# Donut Auction (Fabric, Minecraft 26.2, client-side)

Needs Java 25 + Gradle 9.3+. Build: gradle build -> build/libs/donut-auction-1.0.0.jar
Install: jar + Fabric API (26.2) in mods folder, Fabric Loader 0.19.1+.

Press G -> search/click an item -> timer 1-60s + starting bid -> Start Auction.
Default: bidders /pay you the amount (payments add up); the mod reads the server payment notice.
Toggle to chat "bid 500k" mode in the menu. The mod never sends /pay itself.
